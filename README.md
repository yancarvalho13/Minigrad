# Minigrad

Este repositorio acompanha meus estudos sobre redes neurais, com foco no aprendizado dos algoritmos de backpropagation e nas bases matematicas e computacionais do tema.

O objetivo e compreender, de forma pratica, como modelos neurais sao construidos e treinados, criando uma base solida para estudar e implementar modelos convolucionais.

Autor: Yan da Silva de Carvalho

Engenheiro de software especializado em visao computacional e machine learning.
